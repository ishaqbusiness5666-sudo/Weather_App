# 🌤️ Weather App

A beautiful, responsive weather application that provides real-time weather data and 7-day forecasts for any location worldwide. Built with HTML, CSS, JavaScript, and enhanced with GSAP animations.

## ✨ Features

- **🔍 City Search** - Search any city worldwide with autocomplete suggestions
- **📍 Real-Time Weather** - Get current temperature, humidity, wind speed, and precipitation
- **📅 7-Day Forecast** - View detailed daily forecasts with min/max temperatures
- **🌡️ Temperature Toggle** - Switch between Celsius and Fahrenheit
- **🎨 Beautiful UI** - Modern glassmorphism design with gradient backgrounds
- **✨ Smooth Animations** - GSAP animations for fluid user experience
- **📱 Fully Responsive** - Works perfectly on mobile, tablet, and desktop
- **⚡ Fast & Lightweight** - No heavy dependencies, pure vanilla JavaScript
- **🔐 Proxy Support** - Automatic fallback for ISP-blocked networks (works in Pakistan!)
- **🌍 Global Coverage** - Works worldwide with Open-Meteo free API

## 🚀 Live Demo

## 🐛 Troubleshooting

**Issue**: "Failed to fetch" error
- **Solution**: The app automatically uses proxy. If still failing:
  - Use a VPN (Opera VPN, Cloudflare WARP)
  - Try mobile data instead of WiFi
  - Refresh the page

**Issue**: Search not working
- **Solution**: Type at least 2 characters, check internet connection

**Issue**: Weather data not loading
- **Solution**: Click "Retry with Proxy" button in error message
